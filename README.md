# 二游自动签到

一个纯 Python 的多游戏社区自动签到脚本，零第三方依赖（只用标准库）。

灵感来自 [Trankite/Snap.Voracity](https://github.com/Trankite/Snap.Voracity)（「贪饕」工具箱，C# 写的米游社自动化 + E-Hentai 下载）。

## 二游签到全景矩阵

国内二游的签到只有三种形态，本工具**只做第一种**（有厂商社区 API 的）：

| 类型 | 特征 | 能否自动 | 工具支持 |
|---|---|---|---|
| **① 厂商社区 API** | 官方社区 App + 每日签到接口 | ✅ 稳定 | ✅ **支持** |
| **② 第三方平台** | TapTap / 好游快爆活动页 | ⚠️ 活动 id 每期换 | ❌ 不做 |
| **③ 纯游戏内** | 只能登录游戏领 | ❌ 无法脚本 | ❌ 不做 |

### 为什么不碰 ② 和 ③

- **② TapTap**：活动 id 每次换（如 `ofimj1sv`），签名规则偶尔改，签一周就坏 → 违反「稳定」
- **③ 游戏内**：必须跑游戏客户端（模拟器 + ADB），成本远超收益
- **腾讯微信系**：`wxuin` / `wxsid` / `skey` / `pass_ticket` 一堆凭据，风控极严，跑几次就封

### 没有官方网页签到的（不支持）

- 碧蓝航线（只有游戏内）
- 少女前线 / 蔚蓝档案 / 妮姬（无公开 API）

这类游戏想做自动化只能模拟游戏客户端协议，属于另一套工程量，不在本工具范围。

## 配置

复制 `config.example.json` 为 `config.json`：

```bash
copy config.example.json config.json
```

### 米游社凭据

1. 浏览器打开并登录 https://www.mihoyo.com/
2. F12 → Application（应用）→ Cookies → `https://www.mihoyo.com`
3. 找 `ltuid_v2` 和 `ltoken_v2`（老版本是 `ltuid` / `ltoken`，两个都行）
4. 拼成：`ltuid_v2=xxx; ltoken_v2=yyy`

**uid**：你自己的游戏 UID（原神 9 位、崩铁/绝区零 9 位，见游戏内个人信息）

**region**：
| 游戏 | region |
|---|---|
| 原神（国服） | `cn_gf01`（天空岛）/ `cn_qd01`（世界树） |
| 崩铁 | `prod_gf_cn` |
| 绝区零 | `prod_gf_cn` |
| 崩坏3 | `cn_qd01` |
| 未定 / 鹿鸣 | `cn_gf01` |

### 森空岛凭据（明日方舟 / 来自星尘 / 终末地）

1. 手机或模拟器登录**森空岛 App**
2. 抓包（Charles / mitmproxy / HttpCanary）看  的请求
3. 请求头里的 **** 就是凭据（有效期约 30 天）
4. 填到  的  账号里

签名（）脚本会自动算：，salt 内置在 。

### 塔吉多凭据（异环）

塔吉多是完美世界（老虎账号）的官方社区：https://www.tajiduo.com/

1. 手机登录塔吉多 App / 网页
2. 抓包 `https://bbs-api.tajiduo.com/usercenter/api/login` 的响应
3. 复制 **`refreshToken`**（长期有效，脚本会自动续期）
4. 填到 `config.json` 的 `tajiduo` 账号里

签到接口：
- 社区签到：`POST https://bbs-api.tajiduo.com/apihub/api/signin`
- 游戏签到：`POST https://bbs-api.tajiduo.com/apihub/awapi/sign`（`gameId: 1` = 异环）

塔吉多只需 `Authorization: <accessToken>`，不用额外签名。

### 库街区凭据

1. 浏览器打开并登录 https://www.kurobbs.com/
2. F12 → Application → Cookies → `https://www.kurobbs.com`
3. 找 `userId` 和 `token`

## 用法

```bash
# 跑全部账号

```

## 已知限制

- **米游社的 DS 签名**：部分接口需要 `DS` 头（`salt` + `t` + `r` 的 MD5），本脚本用的是不需要 DS 的老接口，如果哪天失效需要补上签名逻辑
- **国际服**（hoyolab）未实现，接口 domain 和 salt 都不同
- **验证码**：如果账号被风控，签到会返回 `-5003` 之类，本脚本不处理验证码
- **uid 配置**：米游社的 `getAllGameRoles` 接口有时会因为 cookie 权限不足返回空，所以最稳的方式是**手动填 uid**
